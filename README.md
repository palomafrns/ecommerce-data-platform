# Ecommerce Data Engineering Platform

Projeto focado em fundamentos práticos de Engenharia de Dados.

## Pipeline

REST API -> Ingestion -> RAW -> Validation -> Transformation -> STAGING -> PostgreSQL -> Orchestration

## Escopo

- REST API com paginação
- RAW
- validação
- transformação de JSON aninhado
- modelo relacional
- PostgreSQL
- idempotência
- testes
- logs e tratamento de erros
- orquestração
